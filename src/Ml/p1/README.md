# Predicting Boston Housing Prices

* `boston_housing.ipynb` – the completed project (all cells executed, all questions answered)
* `visuals.py` – helper plots (updated for modern scikit-learn)
* `housing.csv` – dataset
* `app.py` – Streamlit GUI

## Run
```
pip install -r requirements.txt
jupyter notebook boston_housing.ipynb     # the notebook
streamlit run app.py                      # the GUI
```
